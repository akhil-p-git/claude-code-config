# Positioning and messaging

Positioning decides the context in which buyers judge the product; copy only expresses it. Method follows April Dunford, *Obviously Awesome*.

## Positioning, in this order
1. **Competitive alternatives** — what customers would really use if this didn't exist (often a spreadsheet, a script, an incumbent, or nothing).
2. **Unique attributes** — capabilities the alternatives lack. Be specific and provable.
3. **Value** — what each attribute lets the customer do, in outcomes they care about; cluster into 2–3 value themes.
4. **Target customers** — the segment that cares most about that value (characteristics you can actually find and reach), not "everyone".
5. **Market category** — the frame that makes the value obvious: an existing category you can win, a subcategory ("X for Y"), or (rarely, expensively) a new one.
6. **Relevant trends** — only if they make the value more urgent for this segment.
Pressure-test: could a competitor say the same sentence? If yes, it isn't positioning.

## Messaging hierarchy
- **One-liner**: "<Product> helps <target customer> <achieve outcome> by <unique approach>" — then rewrite it in plain words a customer would say.
- **Headline** = the main outcome or the sharpest pain removed; **subhead** = how, and for whom.
- **3 value pillars**, each with the attribute that proves it and one proof point.
- **Objection handling** from the context doc's objections list.

## Awareness levels (Eugene Schwartz) — match the message to the reader
Unaware → problem-aware → solution-aware → product-aware → most aware. Cold traffic (ads, HN, Reddit) needs the problem first; returning visitors and comparison searches need specifics, proof, and price.
