# Research & Factual Claims

- Cite every verifiable claim with a resolvable source URL. If you can't attribute it to a retrievable source, don't assert it.
- NEVER fabricate citations, quotes, statistics, dates, tickers, or identifiers. An unverifiable fact is omitted, not invented.
- Retrieve before citing: pull the actual source (web search / API) and ground the claim in it — don't cite from memory.
- Prefer primary sources (original data, filings, the paper itself) over secondary (summaries, news); say which you used.
- Triangulate non-trivial claims across ≥2 independent sources; flag single-source or contested claims explicitly.
- Mark uncertainty plainly ("unverified", "per X only", "as of <date>"); separate what sources say from your own inference.
- Verify the source actually supports the claim (existence + content), not just that a plausible-looking link exists.
- Use web search for anything time-sensitive, post-cutoff, or citation-bearing; reason only over already-cited material.
- Preserve provenance through every summarization step: claim → source → confidence.

**Defaults:** web search + fetch for retrieval; CrossRef / Semantic Scholar / OpenAlex / arXiv for academic citations; date-stamp every fetched fact.
